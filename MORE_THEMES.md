# Assessor / travel / industrial traffic / CEQA GIS (commercial-grade, made by others)

## 1. Assessor maps

These are the legal parcel plates, not a pretty land-use poster.

| Map | Who | URL |
|---|---|---|
| Assessor Maps index | RivCo ACR | https://www.rivcoacr.org/AssessorMaps |
| RivCoView (search APN → assessor PDF) | RivCo ACR | https://rivcoview.rivcoacr.org/ |
| Map My County parcels | RCIT | https://gis1.countyofriverside.us/Html5Viewer/index.html?viewer=MMC_Public |
| Parcel GIS download | RCIT Hub | https://rcitgis-countyofriverside.hub.arcgis.com/pages/data-distribution |
| Parcel REST | RCIT | https://gis.countyofriverside.us/arcgis_mapping/rest/services/OpenData/Assessor/MapServer/40 |

An assessor map shows: book/page, APN, lot lines, recorded dimensions, acreage, street widths, adjoining parcels, recorded map references. No owner name, no address on the plat itself. That is the commercial-grade parcel fabric.

## 4. CEQA GIS maps

CEQA maps are the **figure set inside an EIR / IS-MND / addendum**, hosted on the lead-agency site and on CEQAnet.

| Source | URL |
|---|---|
| CEQAnet (SCH database, full PDFs since 2019) | https://ceqanet.lci.ca.gov/ |
| County Planning project list | https://planning.rctlma.org/projects |
| PLUS Activities GIS | RCIT data distribution + https://gis.countyofriverside.us/arcgis_mapping/rest/services/Transportation/08_PLUS_Mapping_v2/MapServer |
| Example CEQA figure stack (Sunset Crossroads / Banning SP) | regional, location, GP designations, adjacent land use, SP land-use, cumulative projects |
| Example CEQA bio+hydro figures | aquatic features, vegetation communities, watersheds |
| Majestic Freeway Phase II EIR appendices | https://planning.rctlma.org/notice-availability-final-eir-majestic-freeway-business-center-phase-ii |
| Villages of Lakeview SCH 2006071095 | https://ceqanet.lci.ca.gov/2006071095/5 |
| World Logistics Center SCH 2012021045 | https://ceqanet.lci.ca.gov/2012021045/5 |

Standard commercial CEQA GIS figure list:
1. Regional location
2. Vicinity / USGS quad
3. Existing land use / aerial
4. Proposed land use / planning areas
5. Cumulative projects map
6. Vegetation / jurisdictional waters
7. Soils / faults / liquefaction / flood
8. MSHCP cells / survey areas
9. Traffic study area + trip distribution
10. Noise receivers / AQ receptors

Search CEQAnet by County = Riverside + Document Type = EIR. Open the attachments. Those figures are the CEQA GIS.
