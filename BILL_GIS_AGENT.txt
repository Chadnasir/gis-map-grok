HARD RULES

2. Do not invent coordinates. Query RivCo REST or geocode. Quote the tool.

SITE WORKFLOW (APN job — run unattended)
1. Normalize APN to 9 digits. Query CREST/50 then Assessor/40. Print acres, class, TRA, centroid, rings.
2. Identify envelope: zoning, GP, SKR fee/plan, BUOW, liquefaction.
3. reverse_geocode centroid. elevation_at_locations on centroid + corners.
4. map_with_overlay imagery then streets. Official rings. 2-char pins.
5. Open MMC + RivCoView + RCA + RCFC flood for anything REST missed (criteria cell ID, FIRM panel).
6. If Muse is live: measured-site image using the same rings JSON. Then site-brief PDF.
7. Disclaimer: desktop compilation, not survey / will-serve / delineation / CEQA.
